# Protocolo privado — porta 4008

Baseado em `TCP_IP_Protocol - Port 4008-K7560.pdf` do fabricante,
com observações do que funcionou e do que não funcionou na prática.

## Formato do pacote

```
[Header][Data Length][Command][Data][Data Mode][End]
```

| Campo | Tamanho | Valor |
|---|---|---|
| Header | 2 bytes | `0x1B 0x1F` |
| Data Length | 2 bytes | tamanho de `Data` em little-endian (ex: 666 = `0x9A 0x02`) |
| Command | 1 byte | código do comando |
| Data | N bytes | payload (termina com `0x09` se for texto de impressão) |
| Data Mode | 1 byte | depende do comando (ex: número de impressões, slot) |
| End | 2 bytes | `0x1C 0x17` |

## Comandos de status e controle

### Query status

```
Envia:    1B 1F 00 00 0A 00 1C 17
Recebe:   1B 1F 00 00 0C 00 1C 17  → parado
          1B 1F 00 00 0B 00 1C 17  → imprimindo
```

### Enable / Disable printing

```
Enable:   1B 1F 00 00 11 00 1C 17
Disable:  1B 1F 00 00 04 00 1C 17
```

### Heartbeat (teste de conexão)

```
Envia:    1B 1F 00 00 4D 00 1C 17
Recebe:   1B 1F 00 00 4D 00 1C 17
```

### Query device name

```
Envia:    1B 1F 00 00 4C 00 1C 17
Recebe:   1B 1F NN 00 4C <nome> 00 1C 17
```

### Device locked (resposta genérica quando ocupada)

Quando a impressora está em jet on/off, limpeza ou refil, qualquer
comando recebe:

```
1B 1F 00 00 03 01 1C 17
```

## Templates

### Open template (comando 0x43)

**Importante**: este comando **NÃO recarrega se o template já estiver
aberto**. Para apagar o código do leitor USB, use o 0x33.

```
Envia:    1B 1F <len> 00 43 <nome> 00 1C 17
Recebe:   mesmo pacote (echo = sucesso)
Falha:    1B 1F <len> 00 15 <nome> 00 1C 17 (código 0x15 = erro)
```

Exemplo: abrir `test`:

```
1B 1F 04 00 43 74 65 73 74 00 1C 17
```

### Force re-open template (comando 0x33)

**Este é o comando que apaga o código do leitor USB**. Força o reload
do template mesmo que já esteja aberto, zerando tudo que foi inserido
no template.

```
Envia:    1B 1F <len> 00 33 <nome> 00 1C 17
Recebe:   mesmo pacote (echo = sucesso) + notificações 0x39
```

Exemplo real que funcionou com o template "sumi rico":

```
1B 1F 09 00 33 73 75 6D 69 20 72 69 63 6F 00 1C 17
```

O manual diz "0x33 não é recomendado, prefira 0x43" — mas na prática
só o 0x33 serve para apagar o código do scanner, porque o template
está sempre aberto durante a operação.

## Dados de impressão

### Enviar 1 campo em modo cache (0x0E)

```
Envia 1234 1 vez:
1B 1F 05 00 0E 31 32 33 34 09 01 1C 17
                 ^^^^^^^^^^^^   ^^
                 data+term     mode=1 (print once)
```

Responde com três mensagens:

```
1B 1F 00 00 06 ... 1C 17  → recebido
1B 1F 00 00 05 00 1C 17   → enviado ao printhead
1B 1F 00 00 45 00 1C 17   → printhead pronto para imprimir
```

### Modo overwrite (0x2C)

Mesmo formato do 0x0E, mas sobrescreve o printhead imediatamente.

```
1B 1F 05 00 2C 31 32 33 34 09 01 1C 17
```

### Impressão contínua ilimitada (data mode = 0xFF)

```
2 campos "1234" e "test", imprime continuamente:
1B 1F 0A 00 0E 31 32 33 34 09 74 65 73 74 09 FF 1C 17
```

### Clear data cache

```
Envia:    1B 1F 00 00 10 00 1C 17
Recebe:   1B 1F 00 00 10 00 1C 17
```

Apenas limpa o cache de dados de rede. **Não apaga o código do leitor
USB** — para isso use 0x33.

## Slots de variável armazenada

A impressora tem 255 slots independentes para armazenar strings
pré-definidas.

### Guardar (0x1F)

```
Guardar "12345" no slot 0:
1B 1F 06 00 1F 31 32 33 34 35 09 00 1C 17
                                    ^^
                                    slot
```

### Chamar (0x08)

```
Chama slot 0:
1B 1F 06 00 08 00 1C 17
```

Também pode chamar via BCD do conector I/O, ou pelo nome do arquivo de
template (se nomeado em formato BCD).

## Callback de impressão completa (comando 0x16)

Permite a impressora **avisar** cada vez que imprime um produto.

### Habilitar

```
Enable:   1B 1F 00 00 07 01 1C 17
Disable:  1B 1F 00 00 07 00 1C 17
```

### Mensagem automática enviada pela impressora

```
1B 1F 04 00 16 00 1C 17
```

**Importante**: só dispara em impressão real (produto na fotocélula).
Não dispara quando o scanner é usado — pois a impressora só imprime
quando a esteira roda.

## Contadores

### Ler contador

```
Envia:    1B 1F 00 00 3F 00 1C 17
                        ^^
                        0 = product counter, 1..16 = general counters
Recebe:   1B 1F 04 00 3F 37 39 37 38 00 1C 17
                        ^^^^^^^^^^^^
                        valor em ASCII (7978)
```

### Reset contador

```
Envia:    1B 1F 00 00 4F 00 1C 17
                        ^^
                        0 = product counter, 1..16 = general
Recebe:   1B 1F 00 00 4F 00 1C 17
```

### Setar valor de counter geral

```
Setar contador 1 em "123":
1B 1F 03 00 4F 31 32 33 01 1C 17
                           ^^
                           slot do contador
```

## Controle do jato de tinta

### Status

```
Envia:    1B 1F 00 00 29 01 1C 17
Recebe:   1B 1F 00 00 20 01 1C 17 → jet on
          1B 1F 00 00 21 01 1C 17 → jet off
          1B 1F 00 00 29 01 1C 17 → desconhecido
```

### Jet on

```
1B 1F 00 00 20 01 1C 17
            ^^ ^^
            cmd mode: 1=com limpeza, 0=sem
```

### Jet off

```
1B 1F 00 00 21 01 1C 17
            ^^ ^^
            cmd mode: 1=com limpeza, 0=sem
```

## Query alarmes

```
Envia:    1B 1F 00 00 46 00 1C 17
```

Resposta sem alarme:

```
1B 1F 00 00 46 00 1C 17
```

Resposta com alarmes ativos (data mode = 1):

```
1B 1F 20 00 46 <32 bytes de 0/1 ASCII> 01 1C 17
```

Cada byte do data é '0' ou '1' representando o bit do alarme (bits 1
a 32). Por exemplo, com bits 11 e 12 ativos:

```
"00000000001100000000000000000000"
```

## Remote static field update (0x47)

Edita um campo estático de um template remotamente.

```
Exemplo: edita campo 1 do template "1.hik":
coord X=0, Y=0, font 705, char width 1, spacing 1, content "1234"

1B 1F 17 00 47 30 09 30 09 30 09 30 09 30 09 37 30 35 09 31 09 31 09 31 32 33 34 09 01 1C 17
```

## FTP pull (0x49)

A impressora busca arquivos de um servidor FTP.

```
1B 1F <len> 00 49 <path> 09 <user> 09 <pass> 09 <server_ip> 09 <mode> 1C 17
```

Formatos aceitos: `.hik`, `.txt`, `.csv`, `.bmp`

## Pontos práticos da nossa integração

1. **O 0x33 reload template foi a única forma de apagar** o código do
   scanner — bobina 0x0002 do Modbus só limpa cache de rede.

2. **Nome do template exato é obrigatório**: enviar "sumi" em vez de
   "sumi rico" não funciona. Pegue o nome exato na tela principal da
   impressora.

3. **Resposta pode vir com múltiplos pacotes consecutivos**: além do
   echo do comando, podem vir notificações 0x39 e outras. Nosso
   firmware não exige um conteúdo específico — considera "sucesso"
   assim que a conexão TCP é aceita e o write não falhou.

4. **Timeouts generosos**: setamos `setConnectionTimeout(1500)` para
   o connect, e aguardamos até 1,5 s pela resposta. Industrial é
   lento quando a impressora está ocupada (jet on/off).

5. **Fire-and-forget**: para o comando 0x33 (apagar), consideramos
   sucesso mesmo sem receber resposta. Se o pacote foi para o fio,
   a impressora processou — a resposta é só confirmação.
